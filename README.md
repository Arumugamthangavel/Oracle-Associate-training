##  About This Repository

I created this repository to document my progress while learning and working with **Oracle Database and SQL**.

The goal is not just to collect notes, but to build a practical reference that I can use to:

- Revise concepts
- Practice SQL
- Understand Oracle database objects
- Track my progress
- Document practical exercises
- Build a long-term Oracle knowledge base

This repository will be updated continuously throughout my training.
